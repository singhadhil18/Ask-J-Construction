## Validation

- Live baseline: all ten pages at 320, 375, 768 and 1440px in Chromium and WebKit: 80 page/viewport checks and eight intercepted contact-form checks. Images decoded, headers remained sticky, footer links did not overlap, and no page JavaScript errors were reported.
- Live HTTP checks: ten pages, sitemap, robots and release metadata returned 200; HTTP/www/index/extensionless URLs redirected correctly; source paths were blocked and an unknown page returned 404.
- Candidate regression: all ten pages at 320, 390, 768, 980, 1024, 1280, 1359, 1360, 1440 and 1920px in both engines: 200 checks of actual text/control bounds. Project gutters and overlap were checked separately.
- Full journeys at 390×844, 844×390 and 1440×900 in both engines: all seven Services menu destinations, section anchors, quote links from all ten pages, homepage service tiles, About CTA, drawer dismissal/focus and HTTP resources.
- Form checks: whitespace names rejected, correcting input restores validity, international phone and multiline message preserved in WhatsApp URL, draft retained. Email recipient/subject/body encoding checked using a mocked app handoff.
- Testimonial validation, keyboard/touch star rating, close animation, focus, reduced motion, no network submission and no persistence checked in both engines.
- Static audit: 849 local references, fragments, H1s, canonicals, JSON-LD, sitemap and navigation versions passed. All 395 built files matched the source by bytes. Diff whitespace checks passed.
- Corrected-page screenshots reviewed. The landscape anchor check initially measured an in-progress smooth scroll; the test now waits for the heading to enter the visible area. No anchor behavior change was needed.

Browsers: Chromium 153.0.8010.12 and WebKit 26.6. These are emulated browser profiles, not physical Android/iPhone tests. No actual call, email or WhatsApp message was sent. The testimonial form is still a preview, not a review-submission backend. Enquiries still require the visitor to send from their email/WhatsApp application.
